# Sanskriti Ray — Celestial Portfolio

A responsive, single-page portfolio website with a celestial visual style, animated details, clickable project and achievement cards, skill tabs, achievement filters, and a mobile-friendly layout.

## Open locally
1. Extract this folder.
2. Open `index.html` in a modern browser.

No build tools or installation are required.
